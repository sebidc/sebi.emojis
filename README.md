# sebi.emojis

A gallery of 579 stickers in two styles, with individual transparent PNG downloads and complete ZIP packs.

**Website:** https://sebidc.github.io/sebi.emojis/

- Everforest Soft Light palette by default, with a dark mode toggle
- Agrandir titles and Gramatika body text
- Search, category filters, animated previews, Classic / Crayon style selection, and original / 2× downloads
- Complete packs are attached to the GitHub release

Open `index.html` locally, or serve this directory with any static web server. GitHub Pages publishes the `main` branch from the repository root.

## Assets

The Classic sticker artwork was supplied by the repository owner. The Crayon set was generated from those stickers in the owner's approved crayon style, then exported as 512 × 512 transparent PNGs with matching filenames. Font files are the owner's existing assets; their original licenses continue to apply. The Classic 2× PNGs are enlarged versions of the original-resolution exports.

Palette: [Everforest](https://github.com/sainnhe/everforest).
