# sebi.emojis

A gallery of 579 transparent stickers, with individual PNG downloads and complete ZIP packs.

**Website:** https://sebidc.github.io/sebi.emojis/

- Everforest Dark Soft palette
- Agrandir titles and Gramatika body text
- Search, category filters, larger previews, and original / 2× downloads
- Complete packs are attached to the GitHub release

Open `index.html` locally, or serve this directory with any static web server. GitHub Pages publishes the `main` branch from the repository root.

## Assets

Sticker artwork was supplied by the repository owner. Font files are the owner's existing assets; their original licenses continue to apply. The 2× PNGs are enlarged versions of the original-resolution exports.

Palette: [Everforest](https://github.com/sainnhe/everforest).
